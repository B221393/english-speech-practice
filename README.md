# 英語発表の音声練習

英語原稿を聞きながら声に出すための練習ページです。

公開URL: https://b221393.github.io/english-speech-practice/

- 原稿はSummaryまでの本編14ページ、95文の日英対応です。
- 「最初から通し再生」で最初からSummaryまで続けて聞けます。
- ページごと・文ごとの再生、速度と声の選択、一時停止・再開・停止、文の繰り返しに対応します。
- 読み上げ中の英文と直下の日本語を同じ枠で示します。
- 難語・頻出語30語をクリックして聞けます。
- [質問対策](qa.html)には40問の想定質問、短い英語回答、日本語の詳細、式と根拠をまとめています。

音声は端末の読み上げ機能を使います。再生ボタンをタップしてください。英語の声は端末によって異なります。

## 公開方法

mainブランチのルートをGitHub Pagesの公開元にしています。index.htmlとqa.htmlは外部JavaScriptライブラリを使わず動作します。
